# L-PE4.3-Zero-TTS

Telegram-бот для создания качественной озвучки текста с использованием искусственного интеллекта.

---

## Описание

L-PE4.3-Zero-TTS — это Telegram-бот, который преобразует текстовые сообщения в естественную речь с помощью технологии ElevenLabs. Проект предназначен для пользователей, которым необходимо быстро создавать аудио-контент из текста с высоким качеством озвучки.

Бот решает проблему трудоемкого процесса создания аудио-контента, предоставляя простой интерфейс для генерации речи в Telegram.

---

## Функциональные возможности

- **Выбор голоса**: Интерактивное меню для выбора из множества доступных голосов
- **Генерация аудио**: Преобразование любого текста в качественную речь
- **Многоязычная поддержка**: Поддержка различных языков через модель eleven_multilingual_v2
- **Настройка параметров**: Контроль стабильности, схожести и стиля голоса
- **Простой интерфейс**: Интуитивно понятное взаимодействие через Telegram
- **Сохранение настроек**: Персональные настройки для каждого пользователя
- **Логирование**: Подробные логи для мониторинга и отладки
- **Обработка ошибок**: Надежная обработка всех возможных ошибок
- **Веб-интерфейс**: Управление ботом через браузер
- **Система мониторинга**: Отслеживание производительности и уведомления
- **Email и Telegram уведомления**: Алерты о проблемах в реальном времени

---

## Состав и архитектура

- **main.py**: Основной модуль бота с обработчиками команд и сообщений
- **voice.py**: Модуль для работы с ElevenLabs API и генерации аудио
- **web_interface.py**: Веб-интерфейс для управления ботом
- **monitoring.py**: Система мониторинга и уведомлений
- **run_complete.py**: Скрипт для полного запуска всех компонентов
- **start.py**: Скрипт для быстрого запуска и проверки
- **config.py**: Конфигурационный файл с API ключами (не включен в репозиторий)
- **tests.py**: Комплексные тесты для проверки работоспособности
- **run_tests.py**: Скрипт для запуска всех проверок проекта
- **Dockerfile**: Контейнеризация приложения
- **docker-compose.yml**: Упрощенное развертывание с Docker Compose
- **Telegram Bot API**: Обработка пользовательских взаимодействий
- **ElevenLabs API**: Генерация высококачественной речи

## Технологии и инструменты

- **Языки программирования**: Python 3.11
- **Фреймворки и библиотеки**: 
  - telebot (pyTelegramBotAPI)
  - elevenlabs
  - flask (веб-интерфейс)
  - flask-socketio (WebSocket)
- **API и сервисы**: 
  - Telegram Bot API
  - ElevenLabs TTS API
- **Контейнеризация**: Docker, Docker Compose
- **Тестирование**: unittest, mock
- **Логирование**: logging
- **Мониторинг**: requests, smtplib
- **Дополнительные утилиты**: io, time, json, os, threading

## Установка и запуск

### Способ 1: Полный запуск (рекомендуется)

```bash
# Клонировать репозиторий
git clone https://github.com/AntoScher/L-PE4.3-Zero-TTS.git
cd L-PE4.3-Zero-TTS

# Создать конфигурацию
cp config.example.py config.py
# Отредактируйте config.py и добавьте свои API ключи

# Полный запуск всех компонентов
python run_complete.py
```

### Способ 2: Локальная установка

1. Клонировать репозиторий
   ```bash
   git clone https://github.com/AntoScher/L-PE4.3-Zero-TTS.git
   cd L-PE4.3-Zero-TTS
   ```

2. Установить зависимости
   ```bash
   pip install -r requirements.txt
   ```

3. Создать файл конфигурации
   ```bash
   cp config.example.py config.py
   # Отредактируйте config.py и добавьте свои API ключи
   ```

4. Получить API ключи
   - Telegram Bot Token: @BotFather в Telegram
   - ElevenLabs API Key: https://elevenlabs.io/

5. Запустить бота
   ```bash
   python main.py
   ```

### Способ 3: Docker (рекомендуется)

1. Клонировать репозиторий
   ```bash
   git clone https://github.com/AntoScher/L-PE4.3-Zero-TTS.git
   cd L-PE4.3-Zero-TTS
   ```

2. Создать конфигурацию
   ```bash
   cp config.example.py config.py
   # Отредактируйте config.py
   ```

3. Запустить с Docker Compose
   ```bash
   docker-compose up --build
   ```

### Способ 4: Только Docker

```bash
docker build -t lpe4-tts-bot .
docker run -d --name tts-bot -v $(pwd)/config.py:/app/config.py lpe4-tts-bot
```

## Система мониторинга

Автоматический мониторинг включает:
- Отслеживание производительности
- Email уведомления о проблемах
- Telegram уведомления для администраторов
- Генерация отчетов

**Настройка уведомлений:**
Создайте файл `monitoring_config.json`:
```json
{
  "email_notifications": {
    "enabled": true,
    "smtp_server": "smtp.gmail.com",
    "smtp_port": 587,
    "email": "your-email@gmail.com",
    "password": "your-app-password",
    "recipients": ["admin@company.com"]
  },
  "telegram_notifications": {
    "enabled": true,
    "bot_token": "YOUR_BOT_TOKEN",
    "chat_id": "YOUR_CHAT_ID"
  }
}
```
